# Archive Bot

Archive Bot is a Discord bot that saves server messages to daily, per-channel
text files. Server members can use slash commands to retrieve or summarize
saved logs. Summaries are generated by an Ollama model running on a server you
configure.

## Features

- Archives messages, including message text and references to attachments,
  embeds, and stickers, under `logs/<server>/<channel>/<date>.txt`.
- `/log` displays the saved log for one date or a date range of up to seven
  days.
- `/summary` summarizes a saved log for one date or a date range using Ollama.
- `/find` lists every date a word or phrase was mentioned, across all channels
  you can see or in one channel.
- `/clearlog` previews log deletion and requires explicit confirmation before
  deleting a day's log.
- Greets new members in an available text channel.

Logs are stored on the machine running the bot. Keep the `logs/` directory on
persistent storage and restrict access to it: archived messages may contain
private information. Attachment files are not downloaded, but their names and
URLs are included in log entries.

## Requirements

- Node.js 22 or newer and npm.
- A Discord application and bot, with its token and application ID.
- An Ollama server and a model pulled on that server to use `/summary`.

The bot needs the Discord `Guilds`, `GuildMembers`, `GuildMessages`, and
`MessageContent` intents. Enable the privileged **Server Members Intent** and
**Message Content Intent** in the Discord Developer Portal. When inviting the
bot, grant it access to the channels it should archive and the permissions
needed to view channels, send messages, and attach files.

## Setup

1. Install dependencies:

   ```sh
   npm install
   ```

2. Copy `.env-sample` to `.env` and set the values:

   ```dotenv
   TOKEN=your_discord_bot_token
   CLIENT_ID=your_discord_application_id
   OLLAMA_URL=http://127.0.0.1:11434/api/chat
   OLLAMA_MODEL=your_pulled_model
   OLLAMA_NUM_CTX=8192
   SUMMARY_CHUNK_CHARS=12000
   ```

   `OLLAMA_URL` defaults to `http://127.0.0.1:11434` if omitted; it accepts
   either the Ollama base URL or the full `/api/chat` endpoint. The context
   and chunk-size settings are optional. `GUILD_ID` is optional and registers
   commands to one test server instead of globally. `CHANNEL_NAME` is optional
   and selects the preferred welcome channel.

3. Start Ollama and pull the model named in `OLLAMA_MODEL`. For example:

   ```sh
   ollama pull qwen2.5
   ```

4. Register the slash commands with Discord:

   ```sh
   npm run deploy
   ```

   Run this again when command names, descriptions, or options change. Global
   command registration can take time to appear; setting `GUILD_ID` in `.env`
   is useful for testing in one server.

5. Build and start the bot:

   ```sh
   npm start
   ```

Do not commit `.env` or share your bot token. The repository ignores `.env` and
`logs/`.

## Slash commands

| Command | Options | Access |
| --- | --- | --- |
| `/log` | Required `date`; optional `to` and `channel` | Members with **Manage Messages** |
| `/summary` | Required `date`; optional `to` and `channel` | Members with **Manage Messages** |
| `/find` | Required `topic`; optional `channel` | Members with **Manage Messages** |
| `/clearlog` | Required `date`; optional `channel` and `confirm` | Members with **Manage Server** |

Dates can be `YYYY-MM-DD`, `today`, or `yesterday`. For `/log` and `/summary`,
provide `to` to select an inclusive range of up to seven days. If `channel` is
omitted, the command uses the channel where it was run. `/clearlog` affects one
date only; without `confirm: True`, it previews the deletion.
`/find` searches all saved logs, not just seven days. Matching ignores case and
looks for whole words or phrases, so `log` does not match `blog`. Bot messages
are skipped. Results show the newest 15 matching dates, with message counts per
channel and a sample message.

```sh
npm run dev       # Run with nodemon
```
