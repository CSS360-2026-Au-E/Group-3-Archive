# Group — Archive

**CSS 360 – Software Engineering | University of Washington Bothell | Autumn 2026**

Archive is a student team building a Discord bot as our quarter-long software engineering project. This repository is our group's fork of the course example bot. We use it to plan, track, and develop our work.

---

## 📌 Project Status

**Current phase:** Planning / concept selection

We have finished setting up the team environment (GitHub repo, Kanban board, Discord servers). We are now choosing between two bot concepts:

| Concept | Description | Status |
|---|---|---|
| 🎮 **Game Bot** | Lets server members play games in Discord channels, for example trivia, word games, or simple turn-based games. | Under consideration |
| 📝 **Summary Bot** | Summarizes past conversations in a channel so members can catch up on what they missed without scrolling. | Under consideration |

The final direction will be decided and recorded here once the team agrees.
